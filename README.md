# Series Search TV

Модульный Telegram-бот для поиска сериалов в Telegram Inline Mode и перехода к первой серии в TikTok. При первом запуске пользователь выбирает язык, проходит капчу и получает приветствие. Администратор управляет каталогом, приветствиями, рассылками и статистикой.

## Требования

- Windows 10/11 и PowerShell
- Python 3.12
- aiogram 3.15.0
- SQLite (входит в Python)

## Установка

Выполните команды из каталога проекта:

```powershell
if (-not (Test-Path '.venv312\Scripts\python.exe')) { py -3.12 -m venv .venv312 }
.\.venv312\Scripts\python.exe -m pip install -r requirements.txt
if (-not (Test-Path '.env')) { Copy-Item .env.example .env }
```

Если виртуальное окружение или `.env` уже существуют, эти команды не пересоздают и не перезаписывают их.

## Настройка `.env`

Заполните `.env` локально:

```dotenv
BOT_TOKEN=токен_от_BotFather
ADMIN_ACTIVATION_CODE=случайный_секретный_код
ADMIN_IDS=ваш_telegram_id
ADMIN_CODE_ACTIVATION_ENABLED=true
TELEGRAM_REQUEST_TIMEOUT=20
IMGBB_API_KEY=ключ_из_аккаунта_ImgBB
```

`ADMIN_IDS` принимает список разрешённых ID через запятую. Секрет активации не помещайте в исходный код или журналы. Код активации действует только в личном чате и только для ID из `ADMIN_IDS`.

Для фото в inline-поиске создайте API-ключ ImgBB и укажите его в `IMGBB_API_KEY`. Загруженные постеры становятся публичными на ImgBB; используйте только изображения, которые можно размещать публично. Не отправляйте API-ключ в чат и не добавляйте его в код.

Если в журнале появляется `Cannot connect to host api.telegram.org:443`, это проблема сетевого доступа к Telegram API: обработчики кнопок не могут изменить сообщение, пока соединение не восстановится. Разрешите `api.telegram.org:443` в брандмауэре/сети либо укажите SOCKS-прокси, доступный с компьютера бота:

```dotenv
TELEGRAM_PROXY=socks5://127.0.0.1:1080
```

Порт и адрес должны соответствовать реально запущенному прокси; пример сам по себе прокси не создаёт. После изменения `.env` перезапустите бота. `TELEGRAM_REQUEST_TIMEOUT` ограничивает ожидание ответа API, но не может устранить сетевую блокировку.

## Капча

Поместите изображения `1.png`, `2.png`, `3.png`, `4.png`, `5.png` в `assets\captcha\`. В файле `data\captcha_answers.json` задайте для каждого изображения соответствующий пятизначный текстовый ответ, например:

```json
{
  "1": "01234",
  "2": "23456",
  "3": "34567",
  "4": "45678",
  "5": "56789"
}
```

Ответы хранятся строками, поэтому ведущие нули сохраняются. Приведённые ответы — только образец; замените их на ответы для ваших изображений. Если файла изображения или ответа нет, проверка не запускается и бот сообщает о временной недоступности.

## Каталог и приветствие

- Сериал хранится в `data\series.json` с полями `id`, `title`, `tiktok_url`, необязательным Telegram `photo_file_id` и публичным `photo_url` с ImgBB. Пользовательские ссылки должны быть URL TikTok.
- Добавление, редактирование и удаление выполняются через `/admin`; изменения каталога атомарно записываются и доступны сразу.
- При добавлении сериала отправьте фотографию в Telegram или выберите «Без фото». JPG/JPEG поддерживаются, если отправлять их как фотографию, а не как документ. При подтверждении бот отправит постер в ImgBB, а в каталог сохранит Telegram `file_id` и публичный URL. Чтобы добавить миниатюру уже существующему сериалу, замените его фото через `/admin` — загрузится публичная копия. В меню редактирования фото можно заменить или удалить ссылку из каталога; загруженная копия на ImgBB при этом автоматически не удаляется.
- Используется только Inline Mode; поиск названием в личных сообщениях и его FSM-сценарий удалены. Включите inline mode в `@BotFather` (`/setinline`), затем введите `@SeriesSearchTVbot название сериала` в любом чате или нажмите **🔎 Поиск** в меню. Поиск нечувствителен к регистру, поддерживает частичные совпадения и небольшие опечатки. При выборе карточки бот отправит название и ссылку TikTok; постер будет показан как ссылка предпросмотра, если у сериала есть публичный `photo_url`. Отображение предпросмотра зависит от клиента Telegram.
- Переводы хранятся в `locales\ru.json`, `locales\uk.json` и `locales\en.json`. Язык пользователя хранится в поле `users.language` SQLite; при первом `/start` язык выбирается до капчи. Изменить его можно через **⚙️ Настройки → 🌍 Изменить язык**. Неизвестный язык Telegram по умолчанию становится русским.
- Приветствия для каждого языка хранятся в `data\settings.json` (`welcome_texts`) и редактируются через админ-панель с выбором языка.
- ID отслеживаемых сообщений сохраняются в `data\.message_cleanup.json`, поэтому бот может повторить очистку после перезапуска. Тексты и содержимое переписки там не хранятся. Результаты inline-поиска, уже отправленные в другие чаты, бот удалить не может; Telegram также запрещает удалять некоторые старые сообщения.
- При повреждении JSON бот сохраняет резервную копию с суффиксом `.corrupt.*.bak` и не заменяет исходный каталог пустым.
- Перед расширением старой схемы SQLite бот сохраняет копию рядом с фактической базой (`users.db.pre-migration.*.bak`); исходные пользовательские строки сохраняются.

Не редактируйте JSON одновременно с ботом. Перед ручным изменением сделайте копию файла.

## Первый запуск и права администратора

1. Убедитесь, что `.env`, изображения капчи и ответы заполнены.
2. Запустите бота:

   ```powershell
   .\.venv312\Scripts\python.exe .\main.py
   ```

3. Откройте личный чат с ботом и отправьте `/start`.
4. Для ID из `ADMIN_IDS` отправьте `/activate_admin`, затем введите секретный код. Сообщение с кодом удаляется, если это разрешает Telegram.
5. После подтверждения откройте `/admin`.

Права администратора сохраняются в SQLite. Обычные пользователи не получают их через кнопку или callback.

## Административная панель

`/admin` предоставляет управление каталогом, отдельными приветствиями на трёх языках, рассылками и статистикой. Добавление и редактирование используют предварительный просмотр и подтверждение; удаление требует отдельного подтверждения. Операцию можно отменить командой `/cancel` или кнопкой отмены.

Tracked-сообщения очищаются при переходе в меню и `/start`. Шаги админки по возможности обновляют текущее сообщение вместо отправки нового. Если Telegram уже не разрешает удаление сообщения или API временно недоступен, бот запоминает временную ошибку для следующей очистки; сообщения, которые Telegram запрещает удалять, могут остаться в истории.

Рассылка отправляется только зарегистрированным пользователям, которых бот не отметил заблокировавшими его. Она обрабатывает ограничения Telegram, сохраняет состояние и итоговые числа в SQLite и может быть отменена из панели. Если после неожиданной остановки в базе осталась незавершённая рассылка, новая рассылка блокируется. Проверьте частичное выполнение и подтвердите кнопку «Подтвердить остановку и разблокировать»; бот не повторяет рассылку автоматически.

Статистика новых пользователей рассчитывается по UTC. Счётчик завершённых рассылок берётся из SQLite; список сериалов — из JSON.

Промежуточные шаги диалога хранятся в `MemoryStorage` и сбрасываются при перезапуске процесса. Пользователь или администратор может открыть нужный сценарий заново; данные уже подтверждённых изменений и состояние рассылки хранятся отдельно в JSON/SQLite.

## Тесты и проверка синтаксиса

```powershell
.\.venv312\Scripts\python.exe -m pytest -q
.\.venv312\Scripts\python.exe -m compileall -q .
```

Тесты не отправляют реальные сообщения в Telegram. Для ручной проверки API используйте отдельный тестовый бот и не запускайте две копии polling-бота одновременно.

## Структура

- `main.py` — создание Bot/Dispatcher, подключение роутеров и polling.
- `config.py` — настройки из окружения и пути файлов.
- `handlers\` — пользовательские сценарии, админ-панель и FSM.
- `keyboards\` — inline- и reply-клавиатуры.
- `states\` — состояния FSM.
- `services\` — каталог, капча, приветствие, очистка сообщений и рассылка.
- `database\` — схема SQLite, модели и репозиторий.
- `data\` — JSON-каталог, ответы капчи и настройки приветствия.
- `assets\captcha\` — изображения для проверки.
- `tests\` — автоматические тесты.

## Частые проблемы

- **`BOT_TOKEN is missing`** — заполните `BOT_TOKEN` в `.env`.
- **Капча временно недоступна** — проверьте наличие пяти файлов PNG и соответствующих пятизначных ответов.
- **Каталог повреждён** — проверьте сообщение в админ-панели и восстановите JSON из корректной копии; автоматическая очистка файла не выполняется.
- **Не удаётся активировать администратора** — проверьте личный чат, точный Telegram ID, `ADMIN_IDS`, включённый `ADMIN_CODE_ACTIVATION_ENABLED` и непустой `ADMIN_ACTIVATION_CODE`.
- **Нельзя запустить рассылку** — проверьте, не осталась ли в SQLite незавершённая рассылка от аварийной остановки.
