избранное, подтверждения просмотров, ID и новые transport-блокировки уже
доработаны. Актуальные результаты: [CATALOG_PHASE2.md](CATALOG_PHASE2.md),
следующие действия: [DEVELOPMENT_PROGRESS.md](DEVELOPMENT_PROGRESS.md).

Дата: 2026-10-24. Проверка исходного кода и локальных тестов; live Telegram и
Railway не проверялись. Статус «работает» ниже относится к покрытым локальным

## Основные риски, остающиеся после фазы

- Последний удалённый ID сериала может использоваться повторно: требуется
  монотонный счётчик до добавления внешних связей ratings/reviews/watched.
- Общая is_blocked смешивает ban и невозможность доставки рассылки. До
  production требуется разделение причин и сценарий снятия transport-флага.
- Подписка управляется только env, статусы в SQLite пока не обновляются при
  каждой проверке, права самого бота автоматически не проверяются.
- Новые функциональные разделы из ТЗ отсутствуют; существующие тесты не
  подтверждают их работу. Полной готовности к выкладке нет.
- JSON lock рассчитан на один процесс; MemoryStorage сбрасывает незавершённые
  FSM при рестарте. Постоянные user-флаги SQLite при этом сохраняются.
- Первичная загрузка Volume предназначена для отсутствующих JSON. Она не
  переносит пользовательскую SQLite; смена путей требует переноса данных.
- Часть логирующих веток старого кода использует exc_info; перед окончательной
  выкладкой нужна общая фильтрация секретов во всех logging handlers.

Порядок дальнейшей реализации и инструкции переноса: DEVELOPMENT_PROGRESS.md.
